# 수집 탭·데이터 우선 목록 검증

2026-10-29 사용자의 화면 개선 요청에 따른 변경이다.

## 사용 흐름

- C-BAP: 본문 상단의 파일·직접 입력 / Open API 탭. 키보드 방향키·Home/End 지원. API 작업실은 해당 탭을 처음 열 때 조회하고, 탭을 바꾸어도 작성한 설정을 유지한다.
- API 예제: 한국 GDP(JSON), 총인구(XML), 기대수명(JSON). World Bank의 2019~2023년 응답 5개씩을 `scripts/refresh_api_examples.py --refresh`로 실제 확인하고 `frontend/config/api-examples.js`에 보관했다. 응답 확인 시각·공식 통계·API 문서를 표시한다. 설정 가져오기는 편집 폼을 채우며 DB 등록·수집은 명시적 동작이다.
- 공유 데이터셋: C-BAP 두 탭과 카탈로그가 동일 목록을 사용한다. `collection_type` 메타데이터로 API·파일·직접 입력·SQL·분석 결과를 표시한다. 기존 API 테이블은 이름으로 구분하고 구체적인 입력 경로를 모르는 기존 관리 테이블은 파일·직접 입력으로 표시한다. 추가 DDL은 없다.
- R-BAP: 데이터셋·분석 방법을 검색 가능한 목록으로 표시한다. 기본 4종 일괄 분석의 화면·실행 모듈·스타일을 제거했다. 기본/고급 20개 방법은 개별 실행하며, 저장 결과는 검색·페이지 목록에서 다시 연다.
- V-BAP: 데이터셋 선택 → 차트 선택 → 옵션·그래프·연동 그리드. 초기 데이터 목록에서는 TARGET 행을 조회하지 않는다. 저장 인사이트와 R-BAP 결과 전달은 명시된 데이터·차트 설정을 복원한다.

## 누적 목록 제한

| 영역 | 한 페이지 | 높이·탐색 |
|---|---:|---|
| R-BAP 데이터셋 | 6 | 이름·설명·수집유형 검색, 최대 350px 스크롤 |
| R-BAP 분석 방법 | 8 | 이름·설명 검색, 4개 분류, 최대 430px 스크롤 |
| V-BAP 데이터셋 | 12 | 이름·설명·수집유형 검색·필터, 최대 440px 스크롤 |
| 공유 데이터셋·카탈로그 | 20 | 이름·수집유형 검색·필터, 표 최대 580px 스크롤 |

| 저장 분석 | 10 | 최근 200개 요약 중 선택 데이터셋의 결과를 검색·페이지 표시 |
| 수집 배치·실행 이력 | 목록 | 최대 480px 스크롤, 실행 이력은 최근 100회 |

카탈로그 페이징은 이미 읽은 회원별 메타데이터를 대상으로 한다. 서버에서 무제한 데이터셋 전체를 매번 행까지 조회하는 기능이 아니다. TARGET 원본의 조회 상한과 그리드 행 페이징은 기존 정책을 따른다.

## 업데이트 뒤 모듈 export 오류 보완

사용자가 제보한 오류는 `M01001.js`가 요구하는 `mountDatasetCatalog`를 로드한 `M04001.js`에서 찾지 못하는 ES 모듈 연결 오류다. 실제 로컬 서비스와 디스크 파일은 일치했고 해당 export도 존재했지만, 정적 응답에 명시적 재검증·버전 구분이 없어 이전 모듈을 읽은 브라우저 문서와 최신 화면 코드가 섞일 수 있었다.

`backend/frontend_assets.py`가 배포하는 JS·CSS·HTML 콘텐츠로 버전을 생성하고 셸에 nonce로 허용된 import map을 넣는다. 직접·상대·동적 import는 같은 콘텐츠 버전 URL을 사용한다. 셸은 no-store, 정적 JS/CSS/HTML은 no-cache 재검증을 사용한다. 메뉴 HTML의 `X-Frontend-Version`이 문서 버전과 다르면 모듈 로딩 오류를 표시하기 전에 현재 주소로 새로고침한다. 추가 DB 오브젝트나 의존성은 없다.

새 회귀 검사에서 이전 export만 가진 카탈로그 모듈을 로드한 상태, 버전이 다른 메뉴 응답, 현재 C-BAP/카탈로그 버전 URL을 검증한다. 버전 변경 시 세션을 유지해 다시 열고 API 탭이 정상 표시되며 CSP 위반이 발생하지 않음을 확인한다. 별도 Python 검사에서는 하위 모듈 변경에 따른 버전 갱신, import map, nonce 재발급, 304 응답의 재검증 정책을 확인한다.

보완 후 전체 Python 102개와 브라우저 21개가 통과했다. 로컬 9000 서비스를 재시작한 뒤 실제 HTTP 셸·메뉴·카탈로그 모듈의 버전 일치, CSP nonce와 캐시 재검증 헤더도 확인했다.
