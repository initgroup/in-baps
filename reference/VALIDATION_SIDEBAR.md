# 사이드바 사용성 개선 검증

검증일: 2026-10-29

## 변경

- 중복 소개 영역과 하단 안내 카드를 정리하고 메뉴를 세 그룹으로 배치했다.
- 메뉴 자체의 중첩 스크롤을 제거했다. 높이가 부족할 때만 로고·메뉴 공통 영역이 스크롤되며 로그아웃은 하단에 고정된다.
- 데스크톱에서는 76px 아이콘 형태로 접을 수 있다. 브라우저의 `inbaps.sidebar.collapsed` 값으로 표시 선호만 저장하며 회원 권한에는 사용하지 않는다.
- 모바일 메뉴는 닫기 버튼·바깥 영역·Escape·메뉴 선택으로 닫힌다. 열린 동안 배경의 키보드 접근을 막고 메뉴 안에서 초점을 순환한다. 닫기 조작은 메뉴 버튼으로, 메뉴 선택은 본문으로 초점을 이동한다.
- 행 높이 최소 44px, 메뉴 글자 최소 15px을 유지한다. 기존 색상과 활성 메뉴 강조를 보존한다.

## 확인 결과

- `npm.cmd run check`: 프론트 JavaScript 구문 검사 통과.
- `npm.cmd run test:ui`: 13개 통과. 격리 SQLite 회원과 TARGET API 계약 모의를 사용하는 브라우저 회귀 검사이며, 실제 Oracle DML 재검증을 의미하지 않는다.
- 기존 화면 배치 검사 안에서 관리자 메뉴 9개의 표시를 확인했다. 관리자 역할은 메뉴 배치 검증 응답에만 적용하며 서버 회원 권한을 변경하지 않는다.
- 1920×1080, 1366×768, 1280×720에서 모든 메뉴가 공통 스크롤 영역 및 고정 하단 안에 들어오고 스크롤이 필요하지 않음을 확인했다.
- 접기 상태의 새로고침 복원, 아이콘 메뉴 이동, 모바일 390×844의 초점 제한·Escape·바깥 클릭·현재 메뉴 재선택을 확인했다.
- 640×360에서는 고정 로그아웃과 스크롤 영역 내 메뉴의 키보드 접근을 확인했다.
- 실제 `http://127.0.0.1:9000`에서 기존 Oracle 관리자 계정으로 세 데스크톱 해상도, 접기 및 모바일 닫기를 확인했다. 새 연결이나 업무 데이터는 생성하지 않았다.
- 관리자 비밀번호 배포 파일 검사 통과. Git push·Render 배포는 수행하지 않았다.

화면 캡처와 실제 서비스 확인 스크립트는 Git 제외 `.runtime/qa/`에 보관한다.
