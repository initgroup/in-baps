# V-BAP 상세 설정 배치 검증

검증일: 2026-10-29

## 요청과 구현

차트 유형 아래에 있던 상세 설정을 유형과 그래프 사이로 옮겨 함께 보면서 조정하도록 변경했다.

- `frontend/js/M03001.js`: 왼쪽 차트 유형, 가운데 상세 설정, 오른쪽 그래프로 분리했다. 데이터셋·기준 범주/X축·측정값/Y축·두 번째 범주·집계 방식과 차트 적용 버튼은 가운데에 있다. 기존 입력 ID와 차트 생성·저장·재열기 흐름을 유지했다.
- `frontend/css/style.css`: V-BAP 전용 레이아웃을 사용한다. 본문 폭이 900px보다 크면 3열, 600~900px면 유형을 위에 놓고 설정과 그래프를 나란히 표시한다. 600px 이하에서는 유형·설정·그래프 순서로 배치한다. 글자 크기는 유지하고 입력·버튼 최소 높이는 44px이다. R-BAP은 기존 레이아웃을 유지한다.
- 그래프 높이는 데스크톱 창 높이에 맞춰 320~480px 범위에서 조정한다. 모바일은 340px이다.

## 실제 서비스 검증

9000 서비스의 기존 회원 데이터로 게이지와 산점도를 표시하고 집계 조건 변경 후 차트 적용을 확인했다. 업무 데이터·TARGET 설정·저장한 인사이트는 변경하지 않았다.

1920×1080, 1366×768, 1280×720에서는 페이지 스크롤 없이 다음을 확인했다.

- 차트 유형, 상세 설정, 그래프가 같은 높이에서 시작하며 설정은 두 영역 사이에 위치한다.
- 14개 차트 유형 버튼과 상세 설정의 모든 선택란, 차트 적용 버튼이 화면 안에 보인다.
- 게이지(선택란 4개) 및 산점도(선택란 5개)에서 그래프 영역 전체가 화면 안에 보인다.
- 1280×720의 산점도 기준 설정 패널 하단 719px, 적용 버튼 하단 706px, 그래프 하단 652px이다.

1024×768, 900×900, 768×1024, 390×844, 320×740에서도 가로 넘침 없이 설정 적용이 동작했다. 작은 화면에서는 문서 세로 스크롤을 사용한다. 데스크톱 사이드바를 접었을 때도 배치가 정상이다.

좌표 측정과 캡처는 Git 제외 `.runtime/qa/visual-settings-layout.json`, `visual-settings-*.png`에 보관한다.
