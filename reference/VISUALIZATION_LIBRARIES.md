# IN-SIGHT 시각화 엔진 선정

검토일: 2026-10-29. “전 세계 최고”는 단일 객관적 순위가 없으므로, IN-BAPS에 필요한 무료 사용, 다양한 데이터 유형, 상호작용, 유지 관리성, 독립 실행을 기준으로 선택한다.

| 라이브러리 | 공개 라이선스 | 강점 | 적용 판단 |
|---|---|---|---|
| Apache ECharts | Apache-2.0 | 시계열·범주·분포·관계·계층·공간 시각화, Canvas/SVG, 확대·범례·브러시·툴팁, dataset/encode | 기본 IN-SIGHT 엔진. 하나의 설계와 테마로 대부분의 의사결정 그래프를 제공 |
| Vega / Vega-Lite | BSD-3-Clause | 선언형 JSON, 통계 변환, 레이어·패싯·연결 선택 | 향후 정교한 재현형 분석 명세와 편집기를 추가할 때 검토 |
| Plotly.js | MIT | 통계·과학·3D·금융 등 폭넓은 차트와 탐색 | 특화 과학/3D 요구가 명확할 때 보조 엔진으로 검토 |
| Cytoscape.js | MIT | 네트워크 전용 레이아웃, 그래프 이론·관계 분석 | ECharts graph로 부족한 큰 관계망·경로 분석이 요구될 때 검토 |

라이선스와 기능은 공식 자료에서 확인했다. ECharts는 [공식 기능 안내](https://echarts.apache.org/en/feature.html)와 [배포 라이선스](https://github.com/apache/echarts/blob/master/LICENSE), Vega-Lite는 [공식 소개](https://vega.github.io/vega-lite/)와 [라이선스](https://github.com/vega/vega-lite/blob/main/LICENSE), Plotly.js는 [공식 무료 사용 안내](https://plotly.com/javascript/is-plotly-free/), Cytoscape.js는 [공식 문서](https://js.cytoscape.org/)를 근거로 했다.

## 데이터 유형과 표현 계약

| 판단 목적 / 입력 | 추천 그래프 | 검증 조건 |
|---|---|---|
| 시간별 변화 / 날짜 + 수치 | 선, 영역 | 날짜 순서, 결측과 0 구분, 축 단위 |
| 범주별 크기 / 범주 + 수치 | 세로·가로 막대 | 집계 방식(sum/mean/count)과 순서 표시 |
| 전체 중 구성 / 범주 + 비음수 수치 | 도넛, 누적 막대 | 합계와 분모 명시, 음수 거절 |
| 두 수치의 관계 | 산점도, 버블 | 결측 제외 수, 동일 행 대응, 크기 변수 |
| 분포 / 수치 | 히스토그램, 박스플롯 | 구간·사분위 정의, 이상치와 원자료 구분 |
| 변수 간 상관 | 히트맵 | 유효한 쌍의 표본 수, 상수 열의 미정의 상관 |
| 계층 구성 / 경로 + 수치 | 트리맵, 선버스트 | 부모·자식 합계, 누락된 계층 |
| 흐름 / source + target + weight | 생키 | 비음수 가중치, 자기 연결·순환 정책 |
| 개체 관계 / source + target | 네트워크 | 노드 ID 일관성, 중복 간선 처리, 과밀 시 제한 |
| 지역 / 지오메트리 또는 좌표 | 지도·지리 산점도 | 별도 지리 데이터 출처·라이선스와 좌표계 |
| 다변량 비교 | 레이더, 평행좌표 | 단위와 정규화 명시, 축 범위 |
| 텍스트 / 단어 + 빈도 | 단어 빈도 막대, 워드클라우드 | 토큰화 방식·불용어·빈도 정의 |

이 표는 확장 설계 기준이며 모든 유형의 구현 완료 목록이 아니다. 실제 화면의 지원 유형과 검증 범위는 README 및 해당 코드에서 확인한다. 기본 엔진에 존재한다는 사실만으로 제품이 해당 기능을 제공한다고 표기하지 않는다.

## 운영 원칙

- 무료 오픈소스 배포물을 로컬 정적 자산에 포함하고 버전을 고정한다. 런타임 CDN에만 의존하지 않는다.
- 배포하는 실제 버전의 LICENSE/NOTICE를 보존하고 패키지 잠금 파일과 해시를 참조 환경 폴더에 함께 관리한다.
- IN-SIGHT는 제품의 시각화 경험 명칭이며 외부 오픈소스 엔진의 저작권이나 상표를 대체하지 않는다.
- 데이터 매핑·필터·집계·축·차트 유형을 저장하여 다시 열 때 같은 결과를 재현한다.
- 차트마다 표 보기·데이터 내보내기·색상 외 구분·접근성 설명을 제공하는 방향으로 발전시킨다.
- ECharts 공식 자료의 대량 데이터 성능 설명은 이 앱 자체의 처리량 보증이 아니다. 앱 업로드·행 수·분석 제한과 브라우저 렌더링 성능을 별도로 측정한다.
- 추가 엔진은 실제 기능 수요와 데이터 크기가 기본 엔진의 한계를 넘을 때 도입한다. 이 단계의 추천은 4개 엔진 모두를 설치한다는 의미가 아니다.
