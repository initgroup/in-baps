# IN-BAPS 소스 재검토와 선별 반영

2026-10-30 KST. 입력 문서는 [검토 원문](2026-10-30-improvement-input.txt)에 보존했다. 원문의 과거 ‘계획만’ 조건과 달리 이번 사용자 요청은 유용한 범위의 실제 수정이므로, 다음 항목을 선별 구현했다. 기준 소스는 `69fac4e`와 현재 작업 트리다. 기존 분석 20종·차트 14종·API 수집·드릴다운을 없는 기능으로 분류하거나 중복 구현하지 않았다.

## 보류 항목과 구현 순서

1. **이번 선별 반영:** 의미 없는 KPI 방지, 저장 전 데이터 확인, 독립 R/V 입력, 선택 유지, 정확한 조회 범위, 누적 저장 차트 탐색. 기존 객체·레코드를 유지하며 migration 없이 적용한다.
2. **다음 단계:** 선언형 데이터 준비와 조인/유니온 미리보기. 원본 보존, 변환 명세 버전, 파생 데이터셋 관계, 키 중복/행 증폭과 결과 한도, 서버 소유권·동시성 계약을 먼저 설계한다. 기존 JSON RECORD 확장으로 충분한지 검토하고 독립 객체가 필요하면 유일한 다음 migration 번호를 추가한다. 임의 Python·SQL 식 실행은 허용하지 않는다.
3. **분석 안내·방법별 그래프:** 질문과 변수 구조를 기존 20개 분석에 매핑한다. 회귀 계수/신뢰구간·잔차, PCA 점수/설명분산, 군집 중심·프로파일을 실제 산출물에 맞게 표시한다. 기존 진단·해석을 제거하거나 새로 생긴 기능처럼 표시하지 않는다. 각 수치의 서버 결과와 차트 일치 검사 후 제공한다.
4. **수집 증분·재현성:** 업무키/충돌 정책·소유 테이블 DML·checkpoint 성공 조건·불명확 커밋 복구를 함께 설계한다. TARGET 변경과 SYSTEM checkpoint 간 원자성을 가정하지 않는다. 실행 당시 스냅샷·데이터 지문·변환 버전을 선택적으로 보존하는 구조와 기존 결과 호환이 완료 조건이다.
5. **통합 활용:** 태그·의사결정 노트·대시보드 편집·공통 필터·PDF/PPT를 순차 구현한다. 업무 질문/발견/근거/한계/담당자/검토일, 저장 차트와 고정 결과의 기준시점, 삭제 참조 무결성·내보내기 한도를 정의한다. 팀 권한은 기존 회원별 소유권을 대체하지 않고 별도 검토한다.

자동 전체 분석·필수 C→R→V 흐름·데모 로그인·제한의 무조건 증대·실행 시 자동 DDL은 적용하지 않는다. 최상위 메뉴도 추가하지 않았다. 새 패키지 의존성은 없다.

## 검증과 운영 경계

이번 UI 검증은 새 회원 세션·CSRF를 사용하는 격리 SYSTEM SQLite와 명시적 데이터로 수행한다. TARGET 계약을 모의한 검사는 실제 Oracle 적재 검사로 표현하지 않는다. 운영 DB DDL·실제 TARGET 적재·Render 원격 배포는 이 작업 범위에 포함하지 않는다.

완료 조건은 개요 원본 행 요청 없음, 미리보기 무저장과 전체 업로드 한도 검사, R/V TARGET 없이 실제 저장/분석/차트, C TARGET 보존, 잘못된 모듈·소유권·CSRF 거부, 파일 변경 시 확인 무효화, 명시적 진입 데이터 한 번 조회, 저장 차트 목록 선조회 없음, 화면 이동 뒤 늦은 응답 차단, 기존 통계/수집/관리 회귀 통과다. 최종 실행 결과는 아래에 기록한다.

- Python 회원·TARGET·수집·통계·새 미리보기 회귀 **110개 통과**.
- Playwright 전체 초기 26개 중 25개 통과. 남은 1개는 ‘R 파일도 TARGET 필수’라는 이전 검사 기대였으며 이번 요구에 맞게 갱신했다. 지연 모듈 응답 방어와 모바일 파일 확인을 보완한 뒤 R-only 1개·review 3개를 재실행해 **4개 통과**. 중복을 제외하면 최종 구성 **27개 화면 시나리오 모두 검증**했다.
- 차트·드릴다운 모델 **13개**, 개요 모델 **2개** 통과. 개요 전용 실제 회원/격리 브라우저 검사 **1개**도 별도 통과.
- Python/프론트 구문 검사, Oracle 연결 없는 migration plan 통과. V001/V002의 기존 파일·체크섬을 유지하며 신규 DDL 없음.
- 로컬 9000 서비스를 프로젝트 스크립트로 재시작했다. 실제 Oracle TARGET 적재·DDL·Git push·Render 원격 배포는 이 변경에서 수행하지 않았다.

주요 UI 검증 소스는 `tests/ui.spec.cjs`, `tests/context-scope.spec.cjs`, `tests/review-ui.spec.cjs`, 파일 계약은 `tests/upload_preview_test.py`다. 마지막 지연 로딩 검사는 파일 창의 JavaScript 응답을 지연시켜 화면 이동 후 예전 모달이 열리지 않음을 확인한다.
