# 작업 공간·모듈 명칭 검증

검증일: 2026-10-29

## 변경 내용

- 공통 상단 바는 데스크톱 80px에서 64px로 줄였다. 페이지 제목의 위쪽 장식 문구는 제목 옆으로 옮기고, 제목·본문 사이 간격과 바깥 여백을 정리했다. 본문·입력 글자 크기 및 SQL 편집기의 최소 170px 높이는 유지했다.
- C-BAP은 큰 소개 배너와 기존 DB 안내를 간단한 안내로 통합했다. 파일·JSON 카드의 여백을 줄이고 기존 DB 작업실 링크를 제목 옆에 배치했다.
- DB 연결 설정의 SYSTEM/TARGET 설명은 기본적으로 닫힌 펼침 안내로 전환했다. 연결 카드의 상세정보·테스트·목록 설정·SQL 작업실·수정 기능은 유지했다.
- SQL 작업실은 도구 모음과 패널 사이 여백을 줄였다. 공통 진행 창 위치도 새로운 상단 바 높이에 맞췄다.
- 각 모듈 제목 아래에 Collection / Research / Visualization - Bigdata Analysis Platform을 표시한다. V-BAP 제목은 `V-BAP 시각화`, 메뉴 및 개요 카드 보조명은 `데이터 뷰어`다. IN-SIGHT 차트 경험명은 유지한다.

## 회귀 검사

- `npm.cmd run check`: 통과.
- `npm.cmd run test:ui`: 기존 13개 모두 통과. 회원·세션·메뉴·레이어 알림·수집 입력·DB 설정/SQL/그리드 계약·분석·14개 차트·R/V 단독 구성 포함.
- 관리자 비밀번호의 Git 배포 파일/스테이징 포함 여부 검사: 포함 없음.

회귀 검사는 격리 SQLite SYSTEM 및 명시적으로 모의한 TARGET API를 사용한다. 실제 서비스 확인에서는 기존 데이터를 읽고 팝업만 열었으며, Oracle 오브젝트·업무 데이터·TARGET 연결 설정은 변경하지 않았다. 원격 Git/Render 배포는 수행하지 않았다.
