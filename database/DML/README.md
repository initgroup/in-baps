# DML — 기준 데이터·데이터 보정

업무 코드 INSERT/MERGE 또는 데이터 보정 UPDATE는 이 폴더의 `V###__description.sql`로 관리합니다. DDL/ALT와 같은 전역 버전 순서를 사용하며 SQL 문장은 한 줄 `/`로 구분합니다. `backend.migrate plan/status/apply`로 적용 이력을 관리합니다.

현재 필수 기준 데이터 버전은 없습니다. 회원 비밀번호·세션·고객 업무 데이터·TARGET 비밀번호를 버전 SQL에 넣지 않습니다.

합성 예제는 서비스 시작이나 로그인에서 생성하지 않습니다. 회원이 DB 설정의 샘플 생성 기능을 직접 실행하면 선택한 실제 TARGET 테이블에 적재하고 카탈로그에 합성임을 기록합니다. 일반 SQL DML 작업실의 편집은 회원 소유 연결과 쓰기 허용을 검증하며 미리보기는 롤백, 명시적 저장은 커밋합니다. 이 업무 DML을 SYSTEM 버전 migration으로 취급하지 않습니다.
